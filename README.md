# examen-final_mysql
MediSistema

Proyecto de base de datos en MySQL para un centro de salud.

Que hice
Diseñé el modelo de la base de datos (entidades, relaciones y atributos) en draw.io.
Creé la estructura en MySQL Workbench: tablas de médicos, empleados, pacientes, citas, horarios, sustituciones y vacaciones, con sus claves primarias y foráneas.
Inserté datos de prueba en cada tabla.
Resolví las primeras 7 consultas del examen.
Archivos
01_estructura.sql: crea la base de datos y las tablas.
02_datos.sql: inserta los datos de prueba.
03_consultas_1_a_7.sql: consultas del examen.
Como ejecutarlo
Ejecutar 01_estructura.sql en MySQL Workbench.
Ejecutar 02_datos.sql.
Ejecutar las consultas de 03_consultas_1_a_7.sql.
